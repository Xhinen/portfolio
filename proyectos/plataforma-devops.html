Proyecto intermodular de ASIR, curso 2026-2027Final degree project, 2026-2027

Plataforma DevOps autoalojadaSelf-hosted DevOps platform

El supuesto es el Ayuntamiento de Sierra Alta, una entidad ficticia de unos veinte empleados con dos personas en informática. He montado la infraestructura que necesitarían para alojar sus propios servicios con software libre: forja de código con integración continua, gestor de contraseñas, almacenamiento de documentos y la web municipal. No pretende competir con la nube, sino demostrar que una organización así puede operar con medios propios y procedimientos reproducibles. The scenario is the Sierra Alta Town Council, a fictional body with about twenty employees and a two-person IT team. I built the infrastructure they'd need to host their own services on free software: a code forge with continuous integration, a password manager, document storage and the council website. It isn't meant to compete with the cloud, but to show that an organisation that size can run its services in-house with reproducible procedures.

La plataformaThe platform

Toda la definición vive en un repositorio: los nodos se configuran con Ansible y lo que corre en Kubernetes lo aplica Argo CD desde Git. Si el hardware desaparece, la plataforma se reconstruye desde ahí. Everything is defined in one repository: nodes are configured with Ansible, and what runs on Kubernetes is applied by Argo CD from Git. If the hardware disappears, the platform is rebuilt from there.

Cómo llega un cambio a producciónHow a change reaches production

  1. 1

    Push a la forja internaPush to the internal forge

    El código vive en Forgejo, alojado en el propio clúster con su base de datos PostgreSQL y su registro de imágenes.The code lives in Forgejo, hosted on the cluster itself with its PostgreSQL database and image registry.

  2. 2

    Construcción y análisisBuild and scan

    Forgejo Actions construye la imagen en un ejecutor instalado con Ansible y Trivy la analiza. Si encuentra vulnerabilidades críticas, el flujo se detiene y no se publica nada.Forgejo Actions builds the image on a runner installed with Ansible, and Trivy scans it. If it finds critical vulnerabilities, the flow stops and nothing gets published.

    El primer análisis del portfolio encontró 8 vulnerabilidades críticas en la imagen base de Debian. Al cambiar a una base Alpine bajaron a 0.The first scan of the portfolio found 8 critical vulnerabilities in the Debian base image. Switching to an Alpine base brought them down to 0.

  3. 3

    Publicación y actualización del manifiestoPublish and update the manifest

    La imagen se publica en el registro interno con su etiqueta de versión. Cambiar esa etiqueta en el repositorio de manifiestos es, a propósito, un paso manual: es la aprobación antes de pasar a producción.The image is pushed to the internal registry with its version tag. Changing that tag in the manifests repository is a deliberate manual step: it's the approval before production.

  4. 4

    Argo CD sincronizaArgo CD syncs

    Argo CD lee los manifiestos de Git, detecta la diferencia y reconcilia el clúster con ellos. Los secretos viajan cifrados con Sealed Secrets y solo se descifran dentro del clúster.Argo CD reads the manifests from Git, detects the difference and reconciles the cluster against them. Secrets travel encrypted with Sealed Secrets and are only decrypted inside the cluster.

  5. 5

    Reparto progresivo y reversiónGradual rollout and rollback

    La pasarela reparte el tráfico entre la versión anterior y la nueva, y lo observo en Grafana. Para volver atrás basta con revertir el commit: Argo CD devuelve todo el tráfico a la versión 1.The gateway splits traffic between the old and new versions, and I watch it in Grafana. Rolling back just means reverting the commit: Argo CD sends all traffic back to version 1.

Incidencias resueltasIncidents solved

Documenté 44, cada una con su causa raíz y la decisión que tomé. Estas son cuatro de las que más aprendí. I documented 44, each with its root cause and the decision I made. These are four I learned the most from.

Las copias llevaban 74 días sin hacerseBackups hadn't run for 74 days

SíntomaSymptom
Los únicos snapshots eran de julio y el almacén de copias figuraba como inactivo.The only snapshots were from July and the backup store showed as inactive.
CausaCause
El contenedor de Proxmox Backup Server no arrancaba solo tras reiniciar el servidor.The Proxmox Backup Server container didn't start on its own after a host reboot.
SoluciónFix
pct set 104 -onboot 1 y una alerta nueva que avisa si no hay ninguna copia reciente, no solo si una falla.pct set 104 -onboot 1, plus a new alert that fires when there's no recent backup, not only when one fails.

Distribuí la clave SSH privada por errorI shared the private SSH key by mistake

SíntomaSymptom
authorized_keys contenía BEGIN OPENSSH PRIVATE KEY.authorized_keys contained BEGIN OPENSSH PRIVATE KEY.
CausaCause
Al servir ~/.ssh por HTTP descargué id_ed25519 en vez de id_ed25519.pub.While serving ~/.ssh over HTTP I downloaded id_ed25519 instead of id_ed25519.pub.
SoluciónFix
Di la clave por comprometida: par nuevo con frase de paso y authorized_keys sobrescrito en todos los nodos.I treated the key as compromised: a new passphrase-protected pair and authorized_keys overwritten on every node.

Paquetes vulnerables de la imagen base de Debian, como libgnutls.Vulnerable packages in the Debian base image, such as libgnutls.

El medidor se paró antes de la pruebaThe probe stopped before the test

SíntomaSymptom
El script de disponibilidad no tenía datos de la ventana de mantenimiento.The availability script had no data for the maintenance window.
CausaCause
Se había detenido dieciocho minutos antes y no lo comprobé.It had stopped eighteen minutes earlier and I didn't check.
SoluciónFix

Limitaciones conocidasKnown limitations

  • El plano de control está en un solo nodo. En producción real harían falta tres por el quórum de etcd.The control plane runs on a single node. A real production setup would need three for etcd quorum.
  • Los discos no están en espejo: datos y copias van en discos distintos, pero ninguno tiene redundancia.Disks aren't mirrored: data and backups are on separate disks, but neither is redundant.
  • Las copias no salen del edificio, así que la regla 3-2-1 queda incompleta.Backups don't leave the building, so the 3-2-1 rule isn't fully met.
  • Los volúmenes local-path están atados al nodo, y eso explica los seis minutos de corte de los servicios con datos.local-path volumes are tied to their node, which explains the six-minute outage of the stateful services.

Esta web dentro del proyectoThis site inside the project

En la plataforma, este portfolio hace de web municipal. Lo que se evalúa es la infraestructura que la sirve, así que reutilizo una web real en lugar de inventar otra. Corre en el clúster con tres réplicas repartidas entre nodos, un presupuesto de interrupción que mantiene al menos una disponible durante el mantenimiento y políticas de red que limitan quién puede hablar con ella. También está publicada en GitHub Pages, para que siga accesible cuando apago el clúster. On the platform, this portfolio plays the council website. What's being assessed is the infrastructure serving it, so I reuse a real site instead of making one up. It runs on the cluster with three replicas spread across nodes, a disruption budget that keeps at least one available during maintenance, and network policies that limit who can talk to it. It's also published on GitHub Pages so it stays reachable when the cluster is off.
