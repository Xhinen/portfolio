Plataforma DevOps autoalojadaSelf-hosted DevOps platform

La infraestructura que necesitaría la informática de un ayuntamiento pequeño para alojar sus propios servicios con software libre: forja de código con integración continua, gestor de contraseñas, almacenamiento de documentos y la web municipal. Toda la plataforma está definida en un repositorio: si el hardware desaparece, se reconstruye desde ahí. The infrastructure a small town council's IT team would need to host its own services on free software: a code forge with continuous integration, a password manager, document storage and the council website. The whole platform is defined in one repository: if the hardware disappears, it gets rebuilt from there.

Una incidencia realA real incident

Al revisar el inventario descubrí que el servidor de copias llevaba 74 días parado: no tenía activado el arranque automático y nadie se había enterado. Desde entonces la monitorización no solo avisa de que una copia falle, sino también de que no haya ninguna reciente. While reviewing the inventory I found the backup server had been stopped for 74 days: it wasn't set to start on boot and nobody had noticed. Since then, monitoring alerts not only when a backup fails but also when there isn't a recent one.
